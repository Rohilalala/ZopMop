## Source

This audit was generated by running Claude Code over the full ZopMop monorepo
to produce a holistic system walkthrough, then classifying every "loose end"
and "open question" surfaced in that walkthrough as an audit ticket.

The walkthrough document itself is preserved in `.audit/2026-05-08-loose-ends/
SYSTEM_WALKTHROUGH.md` for reference.

## Severity Scale

- **P0** — Launch-blocker. Real users would be harmed (data loss, security,
  money) or feature would be obviously broken at first contact.
- **P1** — Must fix in first month post-launch. UX-broken or operationally
  blind, but won't injure anyone immediately.
- **P2** — Should fix soon. Quality issue, technical debt, future-blocking.
- **P3** — Nice to clean up. Cosmetic, vestigial, low-impact.

## Category Scale

- **SEC** — Security / privacy
- **DATA** — Data integrity / consistency
- **CORR** — Correctness / business logic
- **OPS** — Operational / observability
- **UX** — User experience
- **TECH** — Technical debt
